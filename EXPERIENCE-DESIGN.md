# Sistema de experiencia pública — RUFE V6.1

## Principio

**Explicar → explorar → verificar.**

La ciudadanía no debe conocer el lenguaje técnico del RUFE para poder navegar el portal.

## Capas

1. **Orientación**: hero, guía ciudadana y resúmenes narrativos.
2. **Exploración**: mapa, vivienda, población y evolución.
3. **Verificación**: calidad del dato, metodología, informes, actualizaciones y fuentes.
4. **Gestión interna**: autenticación, edición, revisión, aprobación y publicación.

## Motion

- Revelado suave por scroll.
- Scrollytelling sticky.
- Barras y columnas con crecimiento progresivo.
- Carruseles pasables con scroll-snap.
- Transiciones de ruta discretas.
- Línea sísmica decorativa en el hero.

El movimiento no puede ocultar datos ni ser requisito para acceder a la información.

## Tipografía

La mezcla tipográfica se usa por función, no al azar:

- `Century Gothic` / Avenir / Trebuchet: navegación y lectura.
- Arial Narrow / Aptos Display / Franklin / Impact: titulares fuertes.
- Georgia / Times: cursiva editorial y frases de contraste.
- Segoe Script / Brush Script: acentos puntuales.
- Cascadia Mono / Courier: códigos, fechas y microetiquetas técnicas.
